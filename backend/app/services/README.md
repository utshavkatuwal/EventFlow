# EventFlow API Services

## Available Services

### AuthService
Handles user registration, authentication, and token management.

### EventService
Event creation, retrieval, search, filtering, and statistics.

### AnalyticsService
Dashboard statistics for users, organizers, and admins.

### PublicService
Public event queries and listings.

### FileService
File upload handling with validation.

### FileUtils
Filename sanitization and security utilities.
